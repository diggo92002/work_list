# 工作代辦

這是一個可直接在瀏覽器開啟的單頁工作代辦工具，主程式為 index.html。

## 使用方式

直接以瀏覽器開啟 `index.html`，輸入工作項目、備註、連結、狀態及日期後按「新增」。

## 功能

- 未完成與完成工作切換
- 可開啟或關閉新增工作區
- 連結可複製到剪貼簿，並可在視窗中編輯
- 每筆工作可變更狀態、日期、內容與底色
- 完成項目會自動列在完成頁面，仍可改回其他狀態
- 手機與桌面版自適應排版

## 資料儲存

工作資料儲存在目前瀏覽器的 Local Storage，鍵值為 `Engineering_Work_List`。清除瀏覽器網站資料或改用其他瀏覽器／裝置時，工作清單不會自動同步。
